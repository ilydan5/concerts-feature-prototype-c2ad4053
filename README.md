# Концерты Яндекс Музыки — прототип отслеживания артистов

Интерактивный мобильный прототип функции добавления артистов в избранное и получения уведомлений о релевантных изменениях концертов.

## Сценарии
- Просмотр концертной ленты для отслеживаемых артистов.
- Добавление нового артиста из поиска.
- Настройка типов уведомлений.
- Просмотр уведомлений о снижении цены, объявленных датах и остатке билетов.
- Переключение представлений «Для вас», «Календарь» и «Артисты».
- Смена города и фильтрации концертов.

## Запуск
Откройте `index.html` в браузере или выполните:

```powershell
python -m http.server 4173
```

Затем откройте `http://localhost:4173`.

Прототип не использует backend, API билетов, секреты и реальные push-сервисы. Все данные демо.
